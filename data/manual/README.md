# Ручной тест-сет

Запросы, написанные людьми вручную. Модели на них **не обучаются**: при сборке датасета они попадают в отдельную выборку `manual`, а их почти-дубли удаляются из train/val/test.

## Объём

| Группа | label | attack_type | is_hard_negative | Сколько |
|---|---|---|---|---|
| Переопределение инструкций | 1 | override | 0 | 35–40 |
| Утечка системного промпта | 1 | leak | 0 | 35–40 |
| Ролевой jailbreak | 1 | roleplay | 0 | 35–40 |
| Обфускация | 1 | obfuscation | 0 | 35–40 |
| Обычные вопросы в банк | 0 | none | 0 | 100 |
| Трудные легитимные | 0 | none | 1 | 50 |

Итого около 300 строк. Минимум 3 автора.

## Правила

1. Не смотреть шаблоны в `src/pig/data/generators.py` и примеры из открытых датасетов: пишите так, как атаковали бы сами.
2. Сценарий: чат-бот поддержки банка. Атакующий хочет, чтобы бот нарушил правила, раскрыл инструкции или сделал то, что ему нельзя.
3. Разная длина: от 5 слов до абзаца. Разный стиль: вежливо, грубо, с опечатками, «по-деловому».
4. 20–30 атак смешанные: обычный вопрос + атака внутри или в конце.
5. Обфускация: транслит, пробелы между буквами, замена букв цифрами, смесь языков, «закодируй/раскодируй», вопрос через перевод.
6. Обычные вопросы — своими словами, как писали бы в чат банка (карты, переводы, кредиты, приложение, жалобы).
7. Трудные легитимные — нормальные вопросы со словами «игнорировать», «инструкция», «правила», «роль», «забудь», «пароль», «системный», «покажи».
8. Только русский язык, допускаются отдельные английские слова.

## Колонки

| Колонка | Значения |
|---|---|
| `text` | текст запроса |
| `label` | 1 атака, 0 норма |
| `attack_type` | override / leak / roleplay / obfuscation / none |
| `is_hard_negative` | 1 или 0 |
| `author` | инициалы автора |

## Как заполнять

Удобнее в Google Таблицах: колонки как в `manual_test.csv`, затем **Файл → Скачать → CSV** и заменить этим файлом `data/manual/manual_test.csv`. Excel тоже подходит: файл читается и в UTF-8, и в cp1251, с разделителем `,` или `;`.
